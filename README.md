Tidebreak Isles is a three-island open-world crime game in the spirit of GTA 6: the courier Rook runs goods between Harbour, Night Market and Lighthouse islands by car and by boat, with traffic, pedestrians, a wanted level 0-5 chased by police cars and patrol boats on land and at sea, a 6-mission story, combat, a HUD with minimap, and saving. Built by an AI agent for make.fun's "Make GTA 6" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard and mouse to play.
